/# ShiftTech Design Bible v1.0

A concise master brief.

## Brand Positioning
Founder-led boutique software engineering studio. Direct access to senior expertise. No fake enterprise messaging.
## Benchmarks
Study: Stripe, Linear, Vercel, Clay, Glucode, Netguru, Thoughtbot. Borrow principles, never copy layouts.
## Visual Taste
Editorial, premium, warm, minimal, timeless, Swiss-inspired, generous whitespace.
## Anti-AI Rules
No gradient blobs, glassmorphism overload, stock office people, fake dashboards, crypto aesthetics, excessive animations.
## Homepage
Hero, social proof, services by outcomes, featured work, founder, process, testimonials, insights, FAQ, CTA.
## Conversion
Every page has one primary CTA, trust signals, testimonials, case studies, sticky booking button.
## Design System
8pt spacing, consistent radii, accessible contrast, reusable components.
## Performance
95+ Lighthouse, semantic HTML, accessibility AA, responsive, optimized images.
## Claude Code
Implement reusable components, animations, SEO, accessibility, performance, documentation.
## Fable
Produce UX audit, IA, wireframes, hi-fi screens, design system, motion specs.
