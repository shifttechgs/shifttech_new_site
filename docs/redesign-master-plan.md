# ShiftTech Website Redesign Master Plan

## Objective

Transform ShiftTech into a premium, founder-led software engineering studio that looks and feels world-class while remaining authentic. The goal is **not** to look like a large enterprise agency, but like a boutique consultancy that businesses trust with high-value software projects.

The website should feel handcrafted, human, and premium—not like an AI-generated template.

---

# Core Philosophy

## We are NOT

* A corporate enterprise pretending to have hundreds of employees.
* A generic software agency.
* A template-based Webflow clone.
* A site filled with buzzwords.
* Another "We build innovative software solutions" company.

## We ARE

* Founder-led.
* Premium.
* Boutique.
* Technical.
* Trusted.
* Human.
* Design-conscious.
* Product-minded.

The experience should make visitors think:

> "These people know what they're doing."

# Anti-AI Design Principles

Avoid everything that screams "AI website."

NO:

* Giant gradient blobs everywhere
* Glassmorphism overload
* Random floating shapes
* Overly rounded cards
* Excessive neon
* Cheap stock illustrations
* Generic AI-generated office people
* Fake dashboards
* Robot imagery
* Code backgrounds
* Matrix effects
* Particle animations
* Auto-playing videos
* Too many animations
* Infinite scrolling gimmicks

Instead:

* Real screenshots
* Real product images
* Real founder photography
* Authentic testimonials
* Clean layouts
* Premium iconography
* Carefully crafted motion

Every section should look intentionally designed by a human.

---

# Brand Identity

Keep ShiftTech's identity.

Improve it.

Don't replace it.

Maintain the existing brand colors while refining them into a warmer, more premium palette.

Goals:

* richer contrast
* softer neutrals
* elegant backgrounds
* warmer highlights
* premium shadows
* sophisticated gradients only where necessary

Think:

Modern technology company

NOT crypto startup.

NOT AI startup.

NOT gaming company.

---

# Color Direction

# Success Criteria

Within 5 seconds of landing on the homepage, a visitor should believe:

* ShiftTech builds serious software.
* ShiftTech is premium.
* ShiftTech is trustworthy.
* Working directly with the founder is an advantage.
* This company values craftsmanship.
* They should book a discovery call.

The final result should feel like a cross between **Glucode's credibility**, **Netguru's conversion strategy**, **Stripe's clarity**, **Clay's craftsmanship**, **Linear's typography**, and **Vercel's polish**, while remaining unmistakably **ShiftTech**—a founder-led software engineering studio with warmth, authenticity, and exceptional attention to detail.
